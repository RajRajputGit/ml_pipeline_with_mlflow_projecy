# End-to-End ML Pipeline with MLflow, DVC and DagsHub

## Project Overview
This project demonstrates an end-to-end Machine Learning pipeline with MLOps best practices.

## Features
- Data Versioning using DVC
- Experiment Tracking using MLflow
- Remote Storage using AWS S3
- DagsHub Integration
- Reproducible ML Pipelines
- Git Version Control

## Tech Stack
- Python
- Scikit-Learn
- MLflow
- DVC
- DagsHub
- AWS S3
- Git & GitHub
- UV
